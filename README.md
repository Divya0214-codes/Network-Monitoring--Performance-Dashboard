## 📌 Project Overview

The **Network Monitoring & Performance Analytics Dashboard** is an end-to-end Business Intelligence project developed using **Microsoft Power BI** to analyze and monitor network infrastructure performance.

The project transforms raw network monitoring data into meaningful business and operational insights using **Power Query for data cleaning and transformation, DAX for analytical calculations, data modeling for structured analysis, and interactive Power BI visualizations for monitoring network performance**.

The dashboard provides a centralized view of:

- Device availability
- Online and offline devices
- Bandwidth utilization
- Network traffic
- CPU utilization
- Memory usage
- Network latency
- Packet loss
- Network alerts
- Alert severity
- Interface health
- Device uptime
- Connected users
- Active sessions
- Geographic device distribution

---

# 🎯 Project Objective

The main objective of this project is to build an interactive monitoring and analytics solution that enables users to understand the overall health and performance of network infrastructure.

The dashboard helps IT and network teams to:

- Monitor device availability and operational status
- Identify offline devices
- Detect critical network alerts
- Analyze bandwidth utilization
- Monitor latency and packet loss
- Track CPU and memory utilization
- Analyze network traffic patterns
- Monitor interface performance
- Compare device performance
- Analyze network activity by location
- Identify potential performance bottlenecks
- Support proactive network monitoring and troubleshooting
